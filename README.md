# Язык программирования Runa

Runa — это динамически типизированный интерпретируемый язык программирования, разработанный в рамках курса системного программирования. Синтаксис языка вдохновлен Go.

## Основные характеристики

* **Не ООП:** Язык не использует классы, наследование и виртуальные вызовы. Вместо этого применяется модель методов с получателем (как в Go): `func (v Vector2) length() { ... }`.
* **Tree-walking интерпретатор:** Написан на Rust. Безопасность памяти гарантируется самим Rust (отсутствие `unsafe`, segfaults и утечек памяти).
* **Динамическая типизация:** Проверка типов происходит во время выполнения. Переполнение `int` и выход за границы списков вызывают контролируемые ошибки рантайма, а не панику.
* **Логика:** Поддерживаются символы (`&&`, `||`, `!`) и текстовые операторы (`and`, `or`, `not`).
* **Безопасность (Sandbox):** В языке отсутствует файловый ввод-вывод и доступ к системе, что делает его безопасным для выполнения.

## Сборка и запуск

Убедитесь, что у вас установлен Rust (Cargo). 

Сборка проекта:
```bash
cargo build --release
```
Запуск программы на языке Runa:

```bash
cargo run -- examples/test.runa
```
## Пример кода
```runa
struct Person {
    name,
    age,
}

func (p Person) greet() {
    print("Привет, меня зовут", p.name)
    print("Мне", p.age, "лет")
}

func factorial(n) {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

func main() {
    p := Person { name: "Алиса", age: 25 }
    p.greet()
    
    flag := 10 > 5 && !(10 == 5)
    print("Факториал 5 =", factorial(5))
}

main()
```

## Структура проекта
- `src/lexer/` — лексический анализатор (токенизация).

- `src/parser.rs` — парсер (построение AST).

- `src/interpreter.rs` — интерпретатор (выполнение AST).

- `src/main.rs` — CLI для запуска файлов.

- `examples/` — примеры программ на Runa.

- `tests/` — юнит-тесты лексера.
